# コンフィグモード (v0.1.43)

VR の中で、スティックだけで設定を変えるモードです。決まりの元は作業メモの 01 の 3.2・3.4・3.5 と 04 の 2 章。

## 出入り

- 両スティックを上に倒したまま 1.5 秒 (`CONFIG_GESTURE_SEC`)。HUD の段に `ENTER CONFIG 60%` のように進み具合が黄色で出ます。
- 途中でどちらかを離すと取り消し。両方を上に倒している間は、ゲームのパネルの選びと実行を止めます。
- 出入りのあとは、両スティックを中央に戻すまで普通の操作に戻りません。
- ゲームのパネルの項目 `{"command": "config"}` (test_panels の左 7 番 CONFIG) をトリガーで実行しても入れます。
- コンフィグメニューのルートの 1 番 GAME でも出られます。十字キーモードの間は入れません。

## 入っている間

- ゲームへの出力は止めます。入るとき、パネルで押していたボタンと押していた入力を全部離します。
- 操縦桿とスロットルの軸は、入ったときの値のままです (`CONFIG_HOLD_AXES`)。クルーズも続きます。ブレーキは効きません。
- 左スティック = コンフィグメニュー (8 等分の固定)。倒すと選びます。(v0.1.45) 倒しきって素早く中央に戻すと実行します
  (VRChat のアクションメニュー風。倒したままや、ゆっくり戻したときは選ぶだけ)。左トリガーの半押しでも、選んでいる項目を実行します
  (選択肢の設定は次の値になります)。`CONFIG_EXEC = 'hold'` にすると、0.1.44 までの「倒したまま 0.25 秒」に戻ります。
- 右スティック = 補助。左で設定の項目を選んでいると、値の変え方が出ます。倒しきって素早く戻すたびに 1 回実行します。
  - 選択肢の設定: 1〜n 番にそれぞれの値
  - 数値の設定: 1 = +小、2 = -小、3 = +大、4 = -大、5 = DEFAULT (プロファイルの値に戻す)、6 = UNDO (その項目を選んだときの値に戻す)

## メニュー

| ルート | 中身 |
|---|---|
| 1 GAME | コンフィグモードを出る (v0.1.45) |
| 2 HUD MODE | fakefar / far / plate |
| 3 PROFILE | プロファイルの一覧 (先頭に PREV = 直前のプロファイル。7 個以上なら 8 = NEXT) |
| 4 THROTTLE | THR MODE (A / B)、BRAKE TYPE、BRAKE MAX、BRAKE CURVE、BRAKE SMOOTH、CRUISE ADJ |
| 5 POSITION | RECENTER、HUD UP、HUD DOWN、HUD CENTER |
| 6 LOG | LOG SIZE、LOG CLEAR、VERSION、KEYS (コンソールのキーのオン / オフ)、BTN LOG (ボタンの番号を [BTN] の行で出す)、HUD DBG (HUD のデバッグ用の段を出す / 隠す。0.1.46 から既定は隠す) |
| 7 STICK | アンチデッドゾーン: ADZ ROLL / PITCH / YAW / THR、ADZ BUFFER (v0.1.45) |
| 8 DEBUG | STATS、DIAG、BUS、DRIVE、TRG TEST、PIVOT、DPAD |

## 保存

- 変えた値は自動で保存し、次の起動からも使います。プロファイルのファイルは書き換えません。
  - プロファイルごとの設定 (THROTTLE の中): `users/profiles/<プロファイルのファイル名>`
  - HUD MODE: `users/vc_user.json`
- `users/` はリポジトリの直下 (書けなければ `steam_vr_wheel/media/users/`)。git には入れません。
- 元に戻すには、その項目で右の 5 DEFAULT を選ぶか、`users/` のファイルを消します。

## ほかの v0.1.43 の変更

- クルーズ中にスロットルをつかむと、つかんでいる間はレバーの値で加減速できます。離すとクルーズの値に戻ります。
  `cruise.adjust` = `set` にすると、離したところが新しいクルーズの値になります (`locked` = 0.1.42 と同じ)。
- 項目の `"latch": false` = スティックを中央に戻すと選びが消え、前に選んでいた項目に戻ります (test_panels の右の TGT)。
  パネル全体にも `"latch": false` を書けます。
- 左スティックを倒している間は、右パネルを動かしません (`RIGHT_PANEL_BLOCKED_BY_LEFT`)。

## v0.1.45 のアンチデッドゾーン

- ゲームの側に変えられないデッドゾーン (AC7・AC8 は約 20%) があるとき、出力を 0 からでなく、この値から始めて打ち消します。
- 0.20 が Steam のコントローラー設定のアンチデッドゾーン 6500 に当たります (32767 を 100% とした値)。
- 操縦桿は左右・前後・ひねりを別々に (Steam の「四角」と同じ)、スロットルは 0 からの片側にかけます。
- `stick.adz_buffer` (既定 2%) より小さい入力は 0 のままです (手のぶれでふらつかないように)。アンチデッドゾーンが 0 の軸には、この幅もかけません。
- プロファイルの settings: `stick.anti_deadzone_x`、`stick.anti_deadzone_y`、`stick.anti_deadzone_z`、`throttle.anti_deadzone`、`stick.adz_buffer`
