# VC コンソール (vc_gui.py)

PC の画面に出す設定とログの窓です。ジョイスティック本体とは別のプロセスで動くので、60 Hz のループには触りません。
wxPython 4.0 と Python 3.5 の書き方だけを使っています。

## 起動

リポジトリの直下で次を実行します。

    python -m steam_vr_wheel.vc_gui
    python -m steam_vr_wheel.vc_gui --profile test_panels.json --log C:\path\vc_log.txt

- `--profile` は、プロファイルのタブで最初に選ぶファイルです (省略すると default.json)。
- `--log` は読むログのパスです (省略すると `steam_vr_wheel/media/vc_log.txt`)。
- `--status` / `--cmd` / `--alive` は、コクピット本体との受け渡しファイルです (省略すると `steam_vr_wheel/media/` の `vc_status.json` / `vc_cmd.txt` / `vc_gui_alive.txt`)。本体が自動で付けます。
- すでに 1 つ動いているときは、何も言わずに終わります (二重起動しません)。
- ジョイスティックの起動時に自動で立ち上げる処理は `_joystick.py` 側にあります。

## コクピットとの連携 (0.1.2)

窓の上に、どのタブでも 1 行の帯が出ます。`コクピット: 動作中 v0.1.44 / プロファイル: <名前> (<ファイル>) / コンフィグ中`、または `コクピット: 止まっている`。1 秒ごとに更新します。
`vc_status.json` が無い、または `time` が 5 秒より古いときは「止まっている」です。

- **コクピットのタブ**: 動いているプロファイルの選び + `切り替え` (profile_load) と `読み直し` (profile_reload)、`コンソールを出す` / `コンソールを隠す`、デバッグ命令 (hud_recenter・version・drive_status・bus_status)。止まっているときはボタンが使えません。
- **自動の読み直し**: プロファイルかパネルのタブで保存したファイルが、コクピットの今のプロファイルと同じなら、自動で profile_reload を送ります (ログのタブと状態バーに 1 行出ます)。
- **閉じるとき**: コクピットが動いていれば「コクピットも終了する」「この窓だけ閉じる」「キャンセル」を聞きます。保存していない変更の確認が先です。
- **生存の印**: この窓は `vc_gui_alive.txt` に 1 秒ごと時刻を書きます。本体はこれが新しい間だけ黒いコンソール窓を隠し、止まると (この窓を閉じる・落ちる) また出します。閉じるときはこのファイルを消します。
- 命令は `vc_cmd.txt` に 1 行 1 つの JSON で足します (`{"cmd":"profile_load","file":"x.json"}` など)。

## タブ

### ログ
`media/vc_log.txt` を 250 ms ごとに読み足して出します。最後の 3000 行だけ残します。

- 絞り込み: 入れた文字を含む行だけ出します (大文字小文字は区別しません。例: `[Panel]`)。
- 一時停止: 表示を止めます。裏では読み続け、再開すると追いつきます。
- 消す: 窓の表示だけ消します。ファイルは消えません。
- フォルダを開く: ログのあるフォルダを開きます (Windows だけ)。
- ファイルが縮んだとき (ジョイスティックの再起動) は、先頭から読み直します。

### 設定
古い configurator.py と同じ項目です。`media/config.json` に、変えるたびにすぐ保存します。
`PadConfig` を通して読み書きします。

### プロファイル
`steam_vr_wheel/profiles/*.json` を選び、`settings` の主なキーを編集します。
キーごとに「プロファイルに書く」のチェックがあり、外したキーはファイルに書きません (コードの既定で動きます)。
表にないキー (`input.trigger_*` など) は、読むだけで、そのまま保存されます。

0.1.3 で、本体 v0.1.45 向けの設定を足しました。`stick.anti_deadzone_x / y / z` と `throttle.anti_deadzone` (アンチデッドゾーン: 0 から動き始めた瞬間に、出力をこの値から始める。0.20 ≒ Steam の 6500)、`stick.adz_buffer` (これより小さい入力は 0 のまま)、`dpad.buttons` (null = 十字キーは POV だけ。`1, 2, 3, 4` のように [上, 下, 左, 右] のボタン番号を書くとボタンでも出す。空欄 = null)、`debug.keys` (false = コンソールのキーを使わない)。
パネルの項目の input には `left.x` / `left.y` / `right.a` / `right.b` も書けます (この窓は input 名を検べないので、そのまま通ります)。

### 0.1.3 の直し
- パネルの見本: 最初から描くようにしました (タブを開いたとき・読み込みのあとに描き直す)。
- パネルの木: 名前や割り当てを変えても、木は作り直さず、その行の文字だけ書き換えます。警告の一覧は、中身が変わったときだけ作り直します。
- ログ: 黒い背景に明るい文字 (警告は黄、エラーは薄い赤)。
- 生存の印: `.tmp` に書いてから差し替えるので、読む側が空のファイルを見ることはありません。

### ボタン (0.1.4)

- 左右の ABXY・グリップ・スティックの押し込み・トリガー (引き切り / 半押し / 触れる / 軸) の 16 行の表。行を選んで「変える」で、既定のまま / 出さない / vJoy のボタン / 軸 / パネルの実行 / 区画ボタンを選ぶ。
- 保存すると、既定の割り当てを `input.unbind` で外し、自分の割り当てを `input.bindings` に足す (_joystick.py 0.1.46 から、unbind は既定だけを外す)。
- 表に無い入力は「そのほかの割り当て」で 1 行ずつ足す・直す・消す。`input.base` (default / none) もここ。
- B / Y の番号はコントローラーで違うことがある。コンフィグの LOG ▸ BTN LOG で確かめる。

### 0.1.4 で足した設定

- 設定: `input.trigger_*` (半押し・引き切り・戻しの深さ、二段の方式など 7 個)、`panel.glyph_side`、`panel.glyph_map`。
- プロファイル: `profile.id` / `name` / `note`。
- パネル: 左右のパネルごとの「選びを残す」(`latch`)、項目の `glyph` (自動 / 出さない / 印の名前)、ラベルの欄の「印…」でパッドの印 (`{A}` など) を差し込む。プレビューにも印が出る。

### パネル
`panels` を木で見て編集します。

- 左の木: left_game → フォルダ → スロット、right_game → スロット。
- 真ん中: 選んだスロットのフォームです。種類 (項目・フォルダ・NONE・REST・空)、ラベル、命令と引数、exec (右だけ)、hold、block_a、hud。
- 右: 左パネル (今編集している階層。右を選んでいる間は最後に見た左の階層、無ければルート) と右パネルの丸い見本を並べて出します。編集中の項目は黄色の縁で囲みます。1 番が上で時計回り。灰色 = NONE / REST、赤紫 = 書いていない番号、緑 = 戻る。
- 下: 警告の一覧です。変えるたびに作り直します。見る内容は、スロット 0、8 を超える番号、下の階層の 1、届かない番号、無いフォルダ、フォルダの循環、知らない命令、vjoy_button のボタン無し、右の folder、左の exec、知らないキーなど。ラベルの文字 (A-Z 0-9 空白 / . - +) は情報として出します。
- ボタン: スロットを足す / 消す / フォルダを足す / 上へ / 下へ (番号の入れ替え)。

## 保存

画面上の「保存」「別名で保存」「再読込 (元に戻す)」は、プロファイルとパネルのタブで共通です。

- 保存の前に、古い中身を `<名前>.json.bak` に写します。
- キーの順は format, format_version, profile, settings, input, panels。項目は label, type, folder, command, args, exec, hold, block_a, hud。
- 知らないキーはそのまま残します。ただし JSON の整形は変わります (インデント 2、配列も 1 行ずつ)。
- 保存した中身は、ジョイスティックがプロファイルを読み直したときに効きます (N キーで切り替え、または再起動)。

## まだないもの

- `profile` (id・名前・メモ) と `input` (割り当て) の編集。`input.trigger_*` の編集。
- フォルダを消したときに、そのフォルダを指していた項目の整理 (警告に出るだけ)。
- 元に戻す・やり直しは「再読込」だけです。
- 見本は形の確認用で、HUD の絵とは一致しません。
- 実機の Windows と wxPython 4.0.x では未確認です。作った環境は Linux の wxPython 4.2 でした。
